Objetivo del lab:
Aprender los conceptos básicos de Git y GitHub mediante la creación de un repositorio, el uso de commits, ramas y Pull Requests.

Temas aprendidos durante la práctica:
- Creación y administración de repositorios.
- Uso de commits.
- Creación y uso de ramas.
- Pull Requests y fusión de cambios.
- Consulta del historial de modificaciones.

Lo que más me ha gustado del curso son las guías y herramientas que ofrece para aprender sobre nuevos entornos
